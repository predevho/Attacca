# DOMAIN-IMPORT-CONSTITUTION

외부 공연·입시 공지 후보 반입 도메인 원칙.

> 작성일: 2026-09-13. 이 문서는 원칙을 정의한다. 구현 규칙은 STATUTE에 둔다.

---

## 1. 책임

* KOPIS 공연과 대학 입학처·음악대학 게시판에서 **공지 후보**를 수집한다.
* 후보를 어드민이 승인하거나 거절할 때까지 보관하고, 처리 결과와 수집 실행 이력을 남긴다.
* 승인된 후보는 NOTICE 서비스에 공지 생성을 요청한다.

---

## 2. 원칙

* **수집한 후보는 공개 콘텐츠가 아니다.** `NEW` 상태의 항목은 어드민만 볼 수 있고, 회원·방문자에게는 NOTICE로 승인된 뒤에만 공개된다.
* **외부 자료를 그대로 복제하지 않는다.** 제목·일정·장소·요약 등 심사에 필요한 최소 메타데이터만 보관하고, 본문과 첨부파일은 원문 링크로 안내한다.
* **출처를 잃지 않는다.** 승인으로 만들어진 NOTICE에는 출처 이름과 http(s) 원문 링크를 함께 남긴다.
* **같은 원천 항목은 한 번만 심사한다.** 원천별 고유 키로 중복을 막고, 승인·거절된 항목이 재수집으로 `NEW`가 되지 않게 한다.
* **외부 서버의 정책과 부하를 존중한다.** robots.txt를 판정하고, 식별 가능한 User-Agent와 요청 간격·타임아웃을 적용한다. 허용 여부를 판단할 수 없는 호스트는 건너뛴다.
* **실패를 격리한다.** 한 대학 게시판의 장애가 다른 게시판이나 KOPIS 수집을 막지 않는다.
* **자동 수집 결과를 자동 발행하지 않는다.** 제목·본문·일정·출처를 최종 확정하는 책임은 어드민에게 있다.

---

## 3. 관계

* **NOTICE**: IMPORT가 승인 시 NOTICE 서비스에 공지 생성을 요청한다. 의존 방향은 `IMPORT → NOTICE` 한 방향이며 NOTICE는 IMPORT를 알지 못한다.
* **COMMON**: 승인 중 KOPIS 포스터를 저장할 때 `FileService`를 사용한다. 외부 URL 다운로드는 IMPORT가 검증하고, 파일 저장 방식은 COMMON 규칙을 따른다.
* **MEMBER**: 어드민 권한은 `/api/admin/**` 보안 규칙으로 판정한다. IMPORT 엔티티가 MEMBER 엔티티를 참조하지 않는다.
* **PERFORMANCE**: 관계 없음. KOPIS 항목도 이 기능에서는 NOTICE로만 승격하며 PERFORMANCE로 반입하지 않는다.

---

## 4. 범위 밖 (현재)

* 승인·거절 취소, 수집 항목 삭제, 새 항목 알림.
* 게시판 목록을 관리하는 어드민 화면과 JS 렌더링 게시판 수집.
* KOPIS 외 공연 원천과 PERFORMANCE 반입.
* 외부 게시글 본문·첨부파일 저장.
* 여러 서버 사이의 분산 수집 잠금.
