# 공지 서비스 CQS 분리 실행 계획

## 1. 응답 변환 경계 추출

- `NoticeResponseAssembler` 테스트를 먼저 추가한다.
- 관리자/공개 DTO 변환과 커버 URL 생성을 단일 컴포넌트로 옮긴다.

## 2. 조회 서비스 추출

- `NoticeQueryService`에 관리자·공개 단건/목록 조회를 옮긴다.
- 컨트롤러의 조회 의존성을 새 서비스로 교체한다.

## 3. 변경 서비스 추출

- 컨트롤러의 변경 의존성을 새 서비스로 교체한다.

## 4. 회귀 검증과 문서화
